# Cooking Sandbox

2D falling-sand cooking sandbox in Godot, simulated on the GPU.

## Docs: read when relevant
- `CONTEXT.md`: glossary. Use its terms; avoid the listed synonyms.
- `docs/SPEC.md`: design and the rules the code must keep. Read before changing architecture or behaviour.
- `docs/STATUS.md`: current milestone, open bugs, latest findings. Read at the start of sim work; update it when status changes.
- `docs/papers.md`: reference papers by symptom. Before changing solver, boundary, sand, MPM or fluid-rendering behaviour, read only the matching section; cite what you used.
