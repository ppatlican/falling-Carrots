# falling-Carrots

A 2D side-view particle sandbox in the spirit of OE-Cake, with cooking: liquids, powders, rigid and soft bodies, heat and wind in one GPU particle solver (Godot 4.7.1, compute shaders). The player tunes each material's parameters (viscosity, stickiness, density and so on) and experiments to discover recipes.

- `docs/SPEC.md`: what we're building and the rules the code must keep.
- `docs/STATUS.md`: what works, what's verified, open bugs, and what's next.
- `CONTEXT.md`: the glossary.
- `docs/adr/`: decisions.
